# Vacant Eye

## Senior Design Capstone Project

Vacant Eye is a Raspberry Pi-based computer vision system designed to detect parking-space occupancy.

### Team
- Patrick Hilbert
- Anthony Biley
- Ty Bock
- Tryton Hayes
- Mathews Mandere

### Project Overview
The system uses a Raspberry Pi and camera system to capture parking-lot imagery and computer vision to determine parking-space occupancy.

More information and project documentation will be added as development progresses.
